# CASE STUDY 1: Making Online Shopping Returns Easier

 1.Problem Statement

People sometimes forget to return products they buy online because they have different orders and return deadlines to remember.

 2.Target Users

People who shop online and sometimes need to return products.

 3.User Problems

- Forgetting return deadlines.
- Having orders across different shopping apps.
- Finding it difficult to remember which product needs to be returned first.

 What Do Users Need?

Users need a simple way to remember their return deadlines so they can return products on time.

 4.Customer Journey

1. The user buys a product online.
2. They receive it and decide whether to keep it.
3. If they want to return it, they need to remember the deadline.
4. They open the shopping app and request a return.

Problem:The user might forget the deadline before starting the return.

 5.Opportunity

I saw an opportunity to make return deadlines easier to remember.

A simple tool could show all return deadlines in one place and remind users when a deadline is approaching.

 6.Solution Ideas

I came up with these ideas:

1. A list to save return deadlines.
2. Reminders before the deadline.
3. A page showing all pending returns.
4. Sorting products by return deadline.
5. An option to mark a return as completed.
6. Connecting shopping emails to find order details.
7. Automatically finding return deadlines.
8. A checklist for returning products.
9. A calendar showing return deadlines.
10. A tool to check return rules.

 7.Prioritisation

I compared the ideas based on their impact and how difficult they might be to build.I chose reminders here  because they directly address the problem of forgetting return deadlines. The deadline list helps users save their dates, while reminders help them remember to act. 

| **Idea**                     | **Impact (1–5)** | **Effort (1–5)** |
| ---------------------------- | ---------------- | ---------------- |
| Return deadline list         | 4                | 2                |
| Reminders                    | 5                | 3                |
| Pending returns page         | 4                | 2                |
| Sort by deadline             | 3                | 1                |
| Mark return as completed     | 3                | 1                |
| Connect shopping emails      | 4                | 4                |
| Find deadlines automatically | 4                | 5                |
| Return checklist             | 3                | 2                |
| Return calendar              | 3                | 2                |
| Check return rules           | 4                | 4                |

*These are my initial estimates, not results from user research.*

 8.My Final Solution

I chose to start with a simple tool called **Return Reminder**.

Users can add a product name and its return deadline. The tool shows their upcoming returns and reminds them before a deadline.

For the first version, I would keep only four features:

- Add a product and its deadline.
- View upcoming return deadlines.
- Receive reminders.
- Mark a return as completed.

I chose this idea because it focuses on the main problem without making the product too complicated.

 9.Expected Impact

The tool could help users remember deadlines and manage their returns more easily.

I would check how many users add return deadlines, how many start their returns before the deadline, and whether users find the tool helpful. 

 10.What I Learned

While working on this case study, I learned that it's important to understand the problem before choosing a solution.

I also learned how to come up with different ideas, compare them and choose one to start with.

**Note:** This is my first practice case study. The problem and solution still need to be tested with real users.
